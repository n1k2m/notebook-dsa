# notebook-dsa

Консольный блокнот для хранения событий с датой, временем, местом и описанием. Одни и те же операции реализованы на трёх структурах данных — можно выбрать подходящую и сравнить скорость поиска.

## Структуры данных

| Структура                         | Ключ | Особенности                                                                                                                  |
|-----------------------------------|------|------------------------------------------------------------------------------------------------------------------------------|
| **BST (бинарное дерево поиска)**  | целое число из даты-времени | Простое бинарное дерево поиска без балансировки. На отсортированных данных вырождается в список.                             |
| **AVL (сбалансированное дерево)** | то же, что у BST | Самобалансирующееся дерево: высота ограничена O(log n), поиск стабильнее на больших  и / или отсортированных наборах данных. |
| **HashTable (хеш-таблица)**       | числовой ключ из даты-времени | Реализация с использованием цепочек для разрешения коллизий. Поиск в среднем близок к O(1).                                  |

Для блокнота событий важны быстрый поиск по точному моменту времени и возможность держать записи в хронологическом порядке. Деревья дают сортировку «из коробки», хеш-таблица — быстрый доступ по ключу.

## Результаты бенчмарка

Поиск последнего события в наборе (среднее за 10000 повторов):

| structure | n | time |
|-----------|---|------|
| bst | 100 | 1.708µs |
| avl | 100 | 199ns |
| hashtable | 100 | 97ns |
| bst | 1000 | 14.3µs |
| avl | 1000 | 112ns |
| hashtable | 1000 | 93ns |
| bst | 10000 | 143.763µs |
| avl | 10000 | 100ns |
| hashtable | 10000 | 82ns |

На отсортированном вводе BST вырождается в цепочку, поэтому при росте n его время поиска растёт заметнее. AVL остаётся сбалансированным, хеш-таблица почти не меняет время.

Перезапустите бенчмарк локально, чтобы обновить таблицу:

```bash
go run ./benchmark/
```

## Структура проекта

```
notebook-dsa/
├── main.go              # консольное меню
├── event/event.go       # модель Event и функции работы с событиями
├── bst/bst.go           # бинарное дерево поиска
├── avl/avl.go           # AVL-дерево с поворотами
├── hashtable/hashtable.go # хеш-таблица с цепочками
└── benchmark/main.go    # сравнение времени поиска
```

## Запуск

Требуется **Go 1.20+**.

```bash
go run main.go
```
